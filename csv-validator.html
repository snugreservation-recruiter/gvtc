Important: A browser cannot do SMTP mailbox checks (that needs a backend / paid API like ZeroBounce or NeverBounce). This tool performs DNS MX validation — it confirms the domain actually has a mail server, which catches the majority of dead addresses (typos, expired domains, fake domains). Emails on a live domain but non‑existent mailboxes (e.g. random1234@gmail.com) cannot be detected client‑side.

GoPhish: use the purple GoPhish import button — it produces the exact First Name,Last Name,Email,Position header GoPhish expects under Users & Groups → Import CSV.

Order: the dropdown controls the order of the validated output and of every CSV export. "Random" reshuffles every time you change the dropdown (or re‑run validation).
